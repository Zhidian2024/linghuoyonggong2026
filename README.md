# 灵活用工平台

基于java语言的 灵活用工+灵活用工平台+灵活用工系统+灵活用工小程序+灵活用工源码+灵活用工系统源码

# 一、技术架构

后台服务 springboot+mybatisplus+mysql
用户端 uniapp，支持H5、小程序、APP
管理后台 vue3+elementUi



#  二、角色说明

  # 说明
  
   企业端（支持PC+移动）：企业注册、实名认证、签订协议、创建项目、发包、验收、结算单确认、结算批次查询、税费记录、充值、申报记录、发票记录、合规凭证
  
   灵工端：注册、实名认证（三要素：人脸、身份证、银行卡）、协议签署、接单、签到打卡、提交验收、工作量确认、结算单确认、税费记录、申报记录、完税凭证
  
   平台端：用户管理、实名认证管理、工单任务管理、财务管理、公司核算、银行结算、企业结算单、灵工工资单、税费计算、申报交税、发票凭证、合同协议、 风险审计、报表、大屏
